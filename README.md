# UCD Bioinformatics Course 2026
 
## Course Overview
 
Welcome to the Bioinformatics course at University College Dublin! This repository contains all code, data, and teaching materials for the 2nd week and 2026 cohort. The course provides hands-on training in computational methods for analyzing biological data, with a focus on practical bioinformatics workflows using modern tools and programming languages.
 
## Course Information
 
- **Institution**: University College Dublin (UCD)
- **Instructor**: [Mery Touceda-Suárez](https://github.com/merytouceda)
- **Year**: 2026
- **Format**: In-person

## Course Objectives
 
By the end of this course, students will be able to:
 
- Understand fundamental bioinformatics concepts and data structures
- Work with biological sequence data
- Follow bioinformatics pipelines
- Write and debug bioinformatics scripts in R and/or Python
- Analyze and visualize biological data


## Repository Structure
 
```
ucd_bioinformaticscourse_2026/
├── data/                 # Sample datasets and input files
├── scripts/              # Bioinformatics scripts and code examples
├── slides/               # Lecture slides and presentations
└── README.md             # This file
```

### Contents Overview
 
- **`data/`**: Sample datasets used throughout the course, including sequence files, metadata, and example datasets for hands-on exercises
- **`scripts/`**: R  scripts demonstrating bioinformatics analysis
- **`slides/`**: Lecture slides covering theoretical concepts and practical demonstrations
